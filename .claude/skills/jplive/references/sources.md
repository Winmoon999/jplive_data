# 來源與搜尋關鍵字

本 skill 只收錄日本國內場次。海外場次（含台灣）即使在來源中出現也不寫入資料庫。

## 來源優先順序（confidence 的依據）

| 等級 | 來源 | confidence |
|---|---|---|
| 1 | 藝人／作品／祭典的官方網站、官方公告頁 | `official` |
| 2 | 官方 X 帳號（若能讀取）、事務所／唱片公司／主辦方公告 | `official` |
| 3 | 售票平台的活動頁（e+、ローソンチケット、チケットぴあ、CNプレイガイド、楽天チケット等） | `official`（僅限售票資訊與日期場地） |
| 4 | 場館官方行程表 | `official`（僅限該場館的日期） |
| 5 | 整合情報站、新聞網站、部落格 | `secondary`（必須回頭找官方驗證） |
| 6 | 社群傳聞、未具名消息 | `rumor`（不寫入資料庫，除非使用者要求，且必須標示） |

只有等級 1–4 能讓 `confidence` 設為 `official`。
只有等級 5 的來源，`confidence` 設為 `secondary`。

## 日文關鍵字

| 用途 | 關鍵字 |
|---|---|
| 演唱會 | ライブ、コンサート、ワンマン、単独公演 |
| 巡演 | ツアー、全国ツアー、ホールツアー、アリーナツアー |
| 日程 | 開催日程、公演日程、スケジュール |
| 出演者 | 出演者、出演アーティスト、ラインナップ、第N弾 |
| 票務 | チケット、先行、抽選、一般発売、FC先行、先着、一般 |
| 狀態 | 中止、延期、振替、追加公演、振替公演 |
| 直播／影像 | 配信、ライブビューイング、ライビュ、生中継 |
| 購買限制 | 会員限定、FC会員、日本国内在住、国内電話番号、本人確認、同行者 |

## 票務階段命名

寫入資料庫時，`ticket_phases[].phase` 使用下列固定值（原文放 `label`）：

`fc_presale` / `official_presale` / `lottery` / `first_come` / `general` / `door` / `other`

## 查詢範例

- `{名稱} ライブ 2026`
- `{名稱} ツアー 2026-2027`（跨年度巡演）
- `{名稱} チケット 一般発売`
- `{祭典名} 出演者 第2弾`
- `{作品名} ライブ 公式`

當前年份請以實際日期為準，不要寫死過期的年份。

## 搜尋失敗時

- 官方站抓不到：換 WebFetch 直接讀官網網址；仍失敗就回報「官網暫時無法讀取」。
- 只有整合站有消息：標 `secondary`，並在回覆中明講「尚未在官方來源確認」。
- 完全查不到：回報查過的來源與關鍵字，不要輸出空殼資料。
- WebSearch／WebFetch 可能因法律原因拒絕部分網站，被拒絕就換來源或請使用者自行開啟，不要用其他方式繞過。
