# 類型辨識與搜尋策略

一個對象可以同時屬於多種類型（例如聲優有個人 Live，也有角色企劃 Live）。查詢時要**各類型都檢查**，不要查到一種就停。

## solo：個人歌手／聲優

- 資料來源：本人官網的 Live／Schedule 頁 → 所屬事務所／唱片公司 → 官方 X → 售票平台。
- 搜尋詞：`{名稱} ライブ {年}`、`{名稱} ツアー`、`{名稱} コンサート`、`{名稱} LIVE チケット`。
- 注意：巡演（ツアー）是一個 event，每個場次是一個 performance。
- 聲優：另查其角色企劃（見 franchise），因為很多 Live 是以角色名義舉辦。

## group：團體／偶像／樂團

- 資料來源：團體官網 → 粉絲俱樂部公告 → 經紀公司。
- 偶像團體常有「FC 先行」「會員限定」，票務階段要完整記錄，一般發售日往往比 FC 先行晚很多。
- 成員畢業、休團、解散都會影響活動，注意 `status` 與 `notes`。
- 搜尋詞：`{團名} ライブ`、`{團名} 全国ツアー`、`{團名} ワンマン`。

## festival：多組出演祭典

- 資料來源：**主辦方官網為唯一權威**；個別藝人官網只能當輔證。
- 重點是「出演者名單」與「各日出演分配」。陣容通常分批公布（第 1 彈、第 2 彈……），務必記錄公布階段，且在 `notes` 註明「陣容尚未全部公布」。
- 資料模型：一個 festival 是一個 event，每個開催日是一個 performance，各日出演者放在 performance 的 `performers`。
- 搜尋詞：`{祭典名} {年} 出演者`、`{祭典名} 開催日程`、`{祭典名} チケット`、`{祭典名} 第N弾`。
- 常見：Anisama（Animelo Summer Live）、各季動畫歌曲祭、夏季音樂祭、跨年 Live。名稱以官方為準，不要自己推測。

## franchise：作品／企劃 Live

- 範例：BanG Dream!、K-ON!（けいおん!）、吹響吧!上低音號（響け!ユーフォニアム）、LoveLive!、偶像大師等。
- 資料來源：作品官方網站的 Live／Event 頁 → 製作委員會或發行公司（如 Bushiroad、Pony Canyon、Lantis）→ 官方 X。
- 搜尋詞：`{作品名} ライブ`、`{作品名} コンサート`、`{作品名} 演奏会`、`{作品名} イベント`、`{作品名} 周年`。
- 注意事項：
  1. **有些作品沒有固定的演唱會**。K-ON! 這類完結作品只會偶爾有紀念活動或聯動演出；吹響吧!上低音號的相關演出可能是管樂音樂會、交響樂團演出或活動舞台。查不到就如實回報「目前沒有公開的 Live」，不要硬湊。
  2. 作品相關 Live 的出演者可能是聲優（以角色身分）、現場演奏樂團或交響樂團。`performers` 要記錄實際出演者，並用 `credit_as` 記錄角色或企劃名。
  3. 同一作品會有多個子企劃或樂團（例如不同角色團體），要分開記錄 `franchise_unit`。
  4. 要區分「Live／演唱會」與「活動、握手會、上映會」。只有以演出為主的才收錄；其餘可記在 `kind` 為 `event`，由使用者決定是否需要。

## 不支援的查詢

目前不支援依地點或日期反查（例如「11 月東京有什麼 Live」）。遇到時請說明目前只支援以藝人／活動名稱查詢，並建議改用名稱；使用者提供的時間範圍（如「2027 年上半」）只用來篩選該對象的結果。
